# 项目上下文：帕斯卡两位计算器

本项目把一个可 3D 打印的两位十进制计算机构与配套算术程序放在同一目录，便于跨环境继续开发。当前保存的工程设计为 **V0.2**，目标是先完成两位样机的装配和可靠进位，再考虑扩展。它采用简化的凸轮、滑架和棘爪机构，**不是历史帕斯卡计算器的精确复刻**，也未复现历史 sautoir 储能进位机构。

远端仓库为 `https://github.com/cnbright/pascalline`，项目位于仓库根目录。工具命令均从含 `AGENTS.md` 和 `pascaline.scad` 的项目根目录执行，不依赖原环境的 `/workspace` 路径。仓库当前为公开仓库。

## 从哪里恢复

| 路径 | 用途 |
| --- | --- |
| `pascaline.scad` | 当前 V0.2 参数化 CAD；修改设计从这里开始 |
| `exports/` | 保存的独立 STL、`obj/` 下的 OBJ、零件数量清单及真实网格预览 |
| `ASSEMBLY.md`、`HARDWARE.csv`、`PRINT_START.txt` | 装配、配合修整、外购五金及打印入口 |
| `validation_summary.json` | 保存交付的验证范围、源文件哈希和证据索引 |
| `validation/` | 几何验证脚本、JSON 报告和回程路径数据；部分脚本保留了历史候选的说明，须阅读其范围标记 |
| `software/` | 十进制算术与事件参考程序及单元测试 |
| `tools/`、`requirements.txt`、`docs/REPRODUCE.md` | 基线核对、依赖及副本重建流程 |
| `archive/v1/` | 历史 V0.1，仅供比较，不是当前打印入口 |
| `dist/` | 原始交付 ZIP，作为交付快照保存 |

先执行 `python3 tools/verify_baseline.py`，再执行 `python3 -m unittest discover -s software -v`。需要重新导出或验证时，按 [REPRODUCE.md](REPRODUCE.md) 使用 `tools/rebuild.py` 的独立输出目录。副本内的重建结果用于比对，不自动替换保存的基线。

## 已落实的结构修订

V0.1 的打印弹片方案已替换为三只 **3 mm 厚刚性转动爪**，配金属枢轴套和外置回位元件。驱动爪最大开角 15°，两只止回爪最大开角 25°。驱动爪的打开限位移到尾臂，避免旧限位支承撞到十位止回轴座；鼻端后沿也已减料，为推动时的齿面留出空间。不能重新把树脂梁当弹片掰弯。

滑架采用沿运动方向相隔 36 mm 的两处金属导向，位置为 `(67, -30)`、`(67, 6)` mm。下支承垫片和上限位垫片控制浮动，螺钉的夹紧路径经过金属管。三只爪与滑架合计需要四根外置回位元件，轮盘各有一个外购弹簧钢珠定位柱；不能省略这些配套件后仍视为同一机构。

棘轮为十齿，每档 36°，齿尖半径 17 mm，与数字盘为同一打印件。凸轮升程范围为 **−4.5～+10.4 mm**，滑架总活动范围为 14.9 mm；峰值后退让至 +8.3 mm，让钢珠定位。个位 8→9 还有预行程，必须防止十位提前跳档。

| 个位角度 | 升程变化 | 设计目的 |
| --- | --- | --- |
| 0～36° | +8.3 → −4.5 mm | 0→1 复位 |
| 36～288° | 保持 −4.5 mm | 常规拨数 |
| 288～324° | −4.5 → 0 mm | 8→9 预行程 |
| 324～350° | 0 → +10.4 mm | 进位推动 |
| 350～360° | +10.4 → +8.3 mm | 退让并定位 |

俯视左轮为个位、右轮为十位，正向均为逆时针，读数先看右侧十位。轴距 84 mm，数字盘直径 70 mm。设计基准层为凸轮 Z=6～10、棘轮 Z=14～18、数字盘 Z=21～25 mm；实际爪位置受调整垫片影响，以装配说明为准。CAD 展示的十位角度是规定输入，不是由接触求解得到。

完整交付为 **9 种、13 件打印件**；省去盖板为 8 种、12 件。数字轮、止回爪、下法兰轴套和上隔圈各需两件。数字轮文件以盘面朝下姿态导出，装配时数字面朝上。OBJ 坐标按毫米使用，格式本身不强制单位；不要用整体缩放补偿孔隙。详细尺寸与数量以 `exports/parts.csv` 为准。

## 已有证据与边界

保存的九种网格通过了封闭、方向一致、单连通表面等检查，并核对了 STL→OBJ 的坐标与尺寸。名义几何检查包括凸轮接触采样、工作推动和退让、驱动爪回程、固定件截面，以及个位停在升程 −4.5、0、+8.3 mm 时手拨十位的双爪检查。指定路径未检出所检查的交叠，详见各报告的范围、采样密度与源码哈希。

回程数据是一条几何上可容纳的路径，**不能证明实际弹簧和摩擦会自动选择这条路径**。独立组合高升程与任意较大爪开角仍可能使两爪相碰，相关结果保留在 `section_clearance.json`；实际指定路径和停位手拨检查未经过这些组合。不能宣称“所有姿态无干涉”，操作约束仍为一次拨一个轮、完成定位后再操作另一轮。

`software/simulator.py` 验证十进制状态和有序事件；测试包含 10,000 组两位加法，以及软件多位进位、溢出等情况。软件支持更多位数只是算术能力。**算术测试通过不等于机械验证通过**；软件 `reset()` 加载状态也不代表实体具有同样的复位机构。

目前 **没有实物打印、装配运行、供应商接单验收或寿命试验结果**。未证明弹簧力、摩擦、强度、疲劳、打印公差和钢珠定位在实物中满足要求。材料建议与配合尺寸均是打样起点，需按购入五金实测修整。下一步应依据 [ASSEMBLY.md](../ASSEMBLY.md) 调整轴向间隙、导向、钢珠高度和回位力，并记录至少 100 次慢速进位事件；无实物数据时，应继续准备试验方案或做明确范围的几何检查，不能填写虚构的通过记录。

## 后续开发约束

保留两位交付基线，在新的工作版本中修改设计和生成派生物。CAD 改变后核对五金、打印清单、装配说明及所有受影响的报告，特别注意验证脚本中可能重建而非直接读取的平面参数。预览应从实际网格渲染，区分打印件、装配图和隐藏上层的剖示。

多位扩展需要重新安排凸轮、滑架与传动层，并检查 099→100、999→000 等连续进位的空间、时序和负载。不能直接复制现有两位模块并宣布机械可用；若要反向借位或减法，也需另行设计，不能强转已有止回机构。可复制的接续任务见 [CODEX_PROMPTS.md](CODEX_PROMPTS.md)。
